
# LifeOS AI

An AI-powered personal and professional life management platform.

## Core Features
- Unified dashboard
- Task and routine management
- Notes and daily planning
- Focus timer and screen-time insights
- Guided breathing and calming audio
- AI assistant with validated tools

## Tech Stack
- React, Vite, TypeScript
- Node.js and Express
- MongoDB
- Firebase Authentication
- OpenAI API
